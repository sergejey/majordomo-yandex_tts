Формат файла (текстовый, unicode, каждая запись с новой строки):

слово_для_поиска : слово_для_замены : учитывать_регистр

слово_для_поиска–любая последовательность символов, кроме двоеточия (используйте код &#58; для его замены);
слово_для_замены–любая последовательность символов, кроме двоеточия (используйте код &#58; для его замены);
учитывать_регистр–числовое значение (1 – учитывать, 0 – не учитывать);
разделитель–двоеточие.
📌 Пример экранирования двоеточия

Если в слове для поиска или строке замены есть символ :, его нужно заменить на &#58; – иначе импорт «сломается».

  • Что вы хотите сделать: заменить фразу 10:00 на десять часов
  • Как записать в файле (правильно): 10&#58;00 : десять часов : 0
  • Что получится после импорта: в словарь добавится запись 10:00 → десять часов

Примечание: код &#58; автоматически превратится в обычное двоеточие при импорте, поэтому замена сработает корректно.

📘 Как работает словарь ударений

Словарь ударений применяется к тексту перед отправкой в API синтеза (работает и для v1, и для v3).

  • Ударение: Для принудительной установки ударения используйте символ + (плюс) перед ударной гласной в поле «Строка для замены».
    Пример: загружена → загр+ужена (ударение на «у»).
  • Регистр (флажок «Регистр»):
    • ✔ Включён (учёт регистра) — замена происходит только при точном совпадении регистра букв.
      Пример: дом заменит только дом, но не Дом или ДОМ.
    • ✘ Выключен (без учёта регистра) — замена происходит независимо от регистра (строчные/прописные).
      Пример: дом заменит дом, Дом, дОм и даже ДОМ.
  • Важно: Замена выполняется последовательно в том порядке, в котором записи перечислены в таблице. Если одно слово входит в состав другого, сначала обрабатывайте более длинные варианты.
